PROJECT 01

PLC - Juice Vending Machine

Key Engineering Tasks:

  • • Control Logic Design: Developed ladder logic routines to read user input switches, handle emergency halts, and sequence multi-stage pumping cycles.

PROJECT 02

Autonomous Line Follower Robot

Designed, fabricated, and calibrated an autonomous mobile robotic vehicle engineered to detect, lock onto, and track a predefined track with high precision using sensory closed-loop control logic.

Key Engineering Tasks:

  • • Sensor Array Integration: Interfaced high-sensitivity infrared (IR) optocoupler array to measure road contrast differences between dark guide lines and white surface.
  • • Motor Drive Dynamics: Wired dual DC gear motors through an H-bridge driver circuit with PWM speed modulation for smooth cornering and trajectory stability.
  • • Microcontroller Firmware: Programmed embedded C firmware on microcontroller to achieve instantaneous reactive navigation and prevent line loss.
Microcontroller Embedded C IR Sensor Array L298N Motor Driver DC Gear Motors

Fraud Detection in Banking Transactions

Key Engineering Tasks:

  • • Interactive Streamlit App: Created a full web application with real-time risk gauges, confusion matrix evaluation, and threshold adjustments.
